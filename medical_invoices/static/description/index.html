Medical Invoice

A lightweight Odoo module to generate and manage medical invoices, compatible with Odoo 16

Short Description

Medical Invoice extends Odoo's invoicing with features tailored for clinics and hospitals — itemized treatment codes, patient-facing invoice PDFs, insurance reference fields, and configurable templates for receipts.

Key Features

  • Generate patient invoices from medical services and prescriptions.
  • Attach patient and insurance details to invoices.
  • Custom invoice templates for printable PDFs.
  • Support for tax and discount rules used by clinics.
  • Integration hooks for billing and accounting workflows.
  • CSV import/export for bulk billing.

Compatibility

Tested with Odoo 16.0Works with Community

Installation

  1. Upload the ZIP to Odoo Apps or place the module folder in your addons path.
  2. Update the Apps list and install medical_invoice.
  3. Configure taxes and journal settings under Invoicing → Configuration.

Usage

After installation, go to Invoicing → Medical Invoices to create a new patient invoice.

Important Note

  1. The auto-delivery uses the first warehouse found on the database. Ensure you have a warehouse configured (Inventory → Configuration → Warehouses). If you prefer a specific warehouse, I can change the logic to choose by company or a warehouse field on the invoice.
  2. The picking confirmation/assignment steps are best-effort; depending on your stock rules, lots, and routes, you may need to adapt the code to auto-validate pickings (I avoided forcing validate() to reduce risk).
  3. The import wizard CSV parsing is forgiving but expects product barcodes for reliable matching. I added fallback name search and partner creation by name/email if not found.
  4. You'll likely want to add tests or run this in a staging DB before deploying to production.
